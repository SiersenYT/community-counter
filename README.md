# AmethystCPVP Community Counter

AmethystCPVP Community Counter is a streaming utility designed to display community statistics from YouTube, Twitch, and TikTok in an overlay for streaming software such as OBS Studio.

## Features

- Display YouTube subscriber counts.
- Display Twitch follower counts.
- Display TikTok follower counts.
- Combine community statistics into one streaming overlay.
